# Contributing to Awesome Shadow the Hedgehog

Thanks for helping map the Shadow web.

This directory is intentionally open to more than large, established websites. Personal fan sites, tiny shrines, independent archives, open-source projects, old pages, and niche community resources are welcome when they have a meaningful Shadow the Hedgehog focus.

## Ways to contribute

You can:

1. Open a pull request adding or updating an entry.
2. Open an issue with a URL and a short explanation if you do not want to edit the list yourself.
3. Report a dead, moved, misleading, or unsafe link.
4. Submit an archived/discontinued site for the Historical & Archived Sites section.

## Entry format

Use one Markdown list item:

```md
- [Resource name](https://example.com) — One concise sentence explaining what it is and why a Shadow fan might want it.
```

For historical sites, an Internet Archive link is welcome when the original site is gone.

## What belongs here

Good submissions include:

- Shadow-focused fan sites and shrines
- Shadow archives and preservation projects
- Shadow-focused web tools and open-source projects
- substantial Shadow mods and fan projects
- public communities with a meaningful Shadow focus
- historical Shadow sites and archived pages
- useful reference material substantially focused on Shadow

A larger Sonic resource can be included when it contains an unusually useful Shadow-specific section or project.

## What does not belong here

Please do not submit:

- unrelated or barely related links
- simple search-result pages
- piracy or unauthorized commercial downloads
- malware, deceptive downloads, or unsafe sites
- harassment or hate content
- stores/listings whose primary purpose is selling merchandise
- duplicate entries without a reason

## Descriptions

Keep descriptions factual and compact. Avoid advertising language such as “best,” “#1,” or “must-see.” Say what the resource actually provides.

## Link health

If a site disappears, do not automatically erase its existence. If it has historical value, move it to **Historical & Archived Sites** and add a surviving archive link when possible.

That preservation rule is important to this project: dead fan sites are still part of Shadow web history.

## Pull requests

Please keep a PR focused. A PR that adds one resource is completely welcome — you do not need to make a large contribution.
