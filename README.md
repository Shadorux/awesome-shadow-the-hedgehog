# Awesome Shadow the Hedgehog

> A curated directory of Shadow the Hedgehog websites, archives, projects, tools, mods, communities, and resources.

The Shadow web is scattered across personal sites, archives, GitHub repositories, modding communities, old pages, and tiny corners of the internet. This list exists to make those places easier to discover — and to preserve a map of the Shadow-focused web as it grows.

**Small fan sites and personal shrines are welcome.** This is not limited to large or famous communities.

Maintained by [Shadorux](https://shadorux.dev), a Shadow the Hedgehog web archive and fan-site network.

## Contributing

Found something missing? **Pull requests and issues are welcome.**

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting an entry. The basic rule is simple: the resource should have a meaningful connection to Shadow the Hedgehog and its description should explain why it is useful or interesting.

We especially want to discover:

- independent Shadow fan sites
- personal shrines and old-web pages
- archives and preservation projects
- useful developer projects
- Shadow-focused mods and fan projects
- historical or discontinued websites
- public Shadow communities
